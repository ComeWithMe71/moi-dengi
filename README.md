# Мои деньги

Личный учёт денег: перетаскивайте монетки — доходы, расходы, переводы, лимиты по категориям и отчёты.
Устанавливается на iPhone как приложение (Safari → «Поделиться» → «На экран «Домой»»), работает без интернета,
синхронизируется между устройствами через Supabase.

- `index.html` — всё приложение (без сборки и зависимостей)
- `config.js` — адрес и публичный ключ (anon) Supabase
- `supabase.sql` — таблица и правила доступа: каждый видит только свои данные
- `sw.js`, `manifest.webmanifest`, `icons/` — установка и офлайн-режим

Иконки интерфейса — [Lucide](https://lucide.dev) (ISC). Шрифт — Manrope (SIL OFL).
